Installation sur iPhone et iPad

Ajouter Cap Citoyen à l’écran d’accueil

  1. Ouvrez cette page dans Safari si nécessaire, puis touchez le bouton Partager.
  2. Faites défiler les actions puis choisissez Sur l’écran d’accueil.
  3. Confirmez avec Ajouter.

L’application pourra ensuite être ouverte comme une application classique et continuera de fonctionner hors connexion.
Une nouvelle version de Cap Citoyen est disponible.
